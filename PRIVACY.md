# Privacy Policy

Last updated October 18, 2026

bigbrothermodtools is a set of moderation tools for the moderators of r/BigBrother. It replaces or adds to Reddit's own moderation features for the mod team, and only the subreddit's moderators can use it.

The app runs on Reddit, and Reddit's [Privacy Policy](https://www.reddit.com/policies/privacy-policy) covers how information on Reddit is handled.

## Questions

Send a message to the r/BigBrother moderators through modmail.

## Changes

If this policy changes, the date at the top will change with it.
